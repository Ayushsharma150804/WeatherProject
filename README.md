# 🌤️ Kotlin Weather App

An elegant Android weather application built with **Kotlin**, utilizing the **OpenWeather API** to provide real-time weather data for cities around the world. This project demonstrates a clean implementation of modern Android development practices including Retrofit, ViewModel, LiveData, and Coroutines.

## 📦 Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature, humidity, and pressure
- 💨 Wind speed and weather condition icons
- 🔄 Pull-to-refresh functionality

## 🚀 Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **API:** [OpenWeatherMap](https://openweathermap.org/api)
- **UI:** XML + ViewBinding
